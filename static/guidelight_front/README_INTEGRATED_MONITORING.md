# GuideLight 智能综合监控系统

## 系统概述

基于HFUT-MVNS-main系统的功能分析，我们创建了一个全新的、现代化的综合监控界面，将原有的PyQt5桌面应用程序的所有功能迁移到了Web端，并增强了用户体验和视觉效果。

## 主要功能模块

### 1. 顶部状态栏
- **系统Logo**: 动态脉冲效果，展示系统品牌
- **碰撞预警**: 实时显示碰撞概率，带有颜色编码和动画效果
  - 绿色: 低风险 (0-20%)
  - 橙色: 中等风险 (20-40%) 
  - 红色: 高风险 (40-70%)
  - 闪烁红色: 严重风险 (70%+)
- **系统状态**: 显示运行状态、连接设备数量、运行时间

### 2. 左侧视觉处理面板

#### 视觉算法控制中心
- **目标检测**: YOLOv8实时目标检测算法
- **语义分割**: 场景语义理解和分析
- **深度估计**: 立体视觉深度计算
- **特征追踪**: 运动目标轨迹追踪
- **手势识别**: 手势交互识别
- **空间追踪**: 3D空间物体追踪

每个算法模块都有：
- 状态指示器（运行中/未激活）
- 性能指标显示（处理时间）
- 一键启动/停止功能
- 彩色图标标识

#### 实时视频流展示
- **多路视频流**: 支持最多6路视频同时显示
- **双摄像头支持**: 左右视图分别显示
- **LIVE状态指示**: 实时状态点和文字提示
- **分辨率/帧率监控**: 实时显示技术参数
- **错误处理**: 视频流异常时的友好提示

### 3. 中央BEV和地图区域

#### 鸟瞰图(BEV)环境感知
- **2D/3D视图切换**: 支持多种视角模式
- **实时坐标显示**: 鼠标位置的精确坐标
- **检测对象覆盖**: 显示检测到的物体信息
- **风险等级标识**: 不同颜色表示风险级别
- **数据导出功能**: 支持BEV数据导出

#### 智能导航系统
- **高德地图集成**: 实时地图显示
- **路线规划**: 自动计算最优路径
- **导航控制**: 开始/停止/重新规划
- **位置信息**: 当前位置和目的地显示
- **时间距离预估**: 剩余时间和距离提示

### 4. 右侧数据分析面板

#### 语音交互系统
- **按住说话**: 直观的语音输入方式
- **实时识别**: 语音转文字功能
- **状态指示**: 聆听状态的视觉反馈
- **结果显示**: 识别结果的清晰展示

#### 3D空间音频控制
- **音量调节**: 实时音量控制滑块
- **音效开关**: 空间化、回声、降噪控制
- **频谱可视化**: 20频段实时音频频谱显示
- **HRTF处理**: 头相关传输函数音频处理

#### 智能风险评估
- **实时风险图表**: ECharts动态图表显示
- **风险等级评估**: 低/中/高/严重四级风险
- **碰撞时间预测**: 基于轨迹分析的时间预测
- **最近威胁显示**: 最危险物体的距离和类型
- **建议操作**: AI生成的安全建议
- **历史趋势**: 风险变化趋势图

#### 系统监控终端
- **实时日志**: 彩色编码的系统日志
- **自动滚动**: 可开关的自动滚动功能
- **日志分类**: INFO/SUCCESS/WARNING/ERROR分类
- **时间戳**: 精确的时间记录
- **日志导出**: 支持日志文件导出

### 5. 底部控制栏

#### 系统控制
- **一键启动**: 启动所有算法模块
- **一键停止**: 安全停止所有系统
- **紧急停止**: 强制停止所有操作

#### 性能监控
- **CPU使用率**: 实时CPU占用显示
- **内存使用率**: 内存占用监控
- **GPU使用率**: GPU资源监控
- **进度条可视化**: 彩色渐变进度条

#### 快捷操作
- **截图功能**: 系统截图保存
- **录制功能**: 视频录制功能
- **会话管理**: 保存/加载会话状态

## 从PyQt5到Web的升级

### 原有系统分析
通过分析HFUT-MVNS-main/System_V1中的代码，我们发现原系统包含：
- **主窗口系统**: 多种视觉算法集成
- **云服务架构**: 客户端-服务器通信
- **用户界面**: 语音识别和地图导航
- **3D音频处理**: HRTF空间音频
- **实时数据处理**: 多线程并发处理

### Web端优势
1. **跨平台兼容**: 无需安装，浏览器即可使用
2. **实时协作**: 多用户同时访问监控
3. **移动端支持**: 手机、平板设备适配
4. **云端部署**: 支持云服务器部署
5. **更新便捷**: 无需客户端更新

### 功能增强
1. **更丰富的视觉效果**: CSS3动画和现代UI
2. **更好的交互体验**: 触摸友好的操作方式
3. **更强的扩展性**: 模块化组件设计
4. **更完善的监控**: 系统性能实时监控
5. **更智能的预警**: 多级风险评估系统

## 使用说明

### 1. 系统启动
1. 访问综合监控页面
2. 点击"启动全部系统"按钮
3. 等待所有算法模块初始化完成
4. 观察状态栏显示"系统正常运行"

### 2. 视频监控
1. 在左侧算法控制面板选择需要的算法
2. 点击算法卡片启动对应功能
3. 在视频流区域查看实时画面
4. 根据需要调整视频参数

### 3. 环境感知
1. 在BEV区域查看鸟瞰图
2. 切换2D/3D视图模式
3. 观察检测到的物体标识
4. 查看坐标和距离信息

### 4. 风险监控
1. 关注顶部碰撞概率指示器
2. 查看右侧风险评估面板
3. 根据建议操作调整行为
4. 监控历史风险趋势

### 5. 语音交互
1. 按住语音按钮开始录音
2. 清楚地说出指令
3. 松开按钮完成录音
4. 查看识别结果

## 系统架构

```
前端 (Vue3 + TypeScript)
├── 视觉算法控制
├── 实时视频流
├── BEV环境感知  
├── 智能导航
├── 语音交互
├── 3D音频控制
├── 风险评估
└── 系统监控

后端 (Flask + Python)
├── 视频流处理
├── 算法模块管理
├── 数据库操作
├── API接口服务
└── WebSocket通信

硬件设备
├── OAK-D摄像头
├── 深度传感器
├── IMU传感器
├── 音频设备
└── 定位模块
```
